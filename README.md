# Доровик Артём - МИБ-601
## Лабораторная **№3**
## Вариант: **8**
## Задание: **Оценка рюкзака у скупщика
В input.txt хранится прейскурант местного торговца в формате Название_предмета Цена (например: Дерево 15, Камень 20, Семена_пшеницы 5). Программа должна пройтись по текущему инвентарю игрока (inventory), сопоставить каждый непустой слот с его текстовым названием из каталога item_names, найти цену этого предмета в input.txt и сформировать в output.txt оценочную ведомость: стоимость каждого слота, самый дорогой предмет в рюкзаке и общую сумму, которую игрок выручит при продаже всего инвентаря (если предмета нет в прайс-листе, его цена равна 0).
