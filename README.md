## Задание: Система веса и Перегруз (struct Backpack и enum LoadState) 
Превратите массив инвентаря в полноценную структуру struct Backpack (массив слотов, текущий общий вес, макс. грузоподъёмность, статус загрузки через enum: Налегке, Норма, Перегруз). Каждому ID предмета задаётся свой вес. Если набрать полный рюкзак тяжёлых камней, наступает «Перегруз» — каждый шаг в походе начинает отнимать 3 ед. выносливости вместо 1. В меню можно докупать подсумки за золото, повышая грузоподъёмность.
